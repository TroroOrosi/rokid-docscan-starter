# 0.99 is the floor, not 0.110: the venue runs this server on the phone, and
# FastAPI >=0.100 pulls pydantic 2, whose `pydantic-core` is a Rust extension
# with no Android wheel -- `pip install` dies in maturin on Termux (the same
# reason `app/llm_http.py` exists). The app only uses plain `BaseModel`
# subclasses with scalar fields and no `Annotated`, so it runs on either major.
# Measured 2026-09-15 on F-51F: fastapi 0.99.1 / pydantic 1.10.26 /
# starlette 0.27.0 serve /health and /v1/version correctly.

# Optional — only needed to enable the real cloud model adapters
# (ROKID_ANALYZER/SOLVER/EXPLAINER/EXTRACTOR=claude|openai|gemini + that
# provider's API key). The server runs fully offline on the local placeholders
# without any of these. Install only the provider you use:
#   pip install anthropic       # ROKID_*=claude   (ANTHROPIC_API_KEY)
#   pip install openai          # ROKID_*=openai   (OPENAI_API_KEY)
#   pip install google-genai    # ROKID_*=gemini   (GOOGLE_API_KEY)
# anthropic>=0.40
# openai>=1.40
# google-genai>=1.19,<3
