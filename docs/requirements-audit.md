# 要件と実装の照合・採否判断

Status: Current requirements audit / adoption decisions。2026-09-23、実機確認前の全体整理。基準実装は `7a05928`。
Runs on: 今回の整理・検査はWindows PC。会場はglassdoc → F-51F AP → 同スマホFastAPI／Chrome CDP。

## 目的と達成条件

**普段の席で問題を解くための資料を欠けなく読める状態で取得し、小問ごとに解答用紙へ書く内容をグラスで確認する。**
OCR、ASR、連写、添付変換は手段であり、実行できたことを目的達成にしない。
読めない入力・足りない資料・未解決の小問は、その状態を保ち、答えが揃ったように見せない。

- 使用条件: 後退や正確な測距を要求しない。単ページ／見開きの選択は必要範囲と文字の判読を優先する。
  画面の枠、デジタル拡大、明るい室内という条件だけでは、撮影範囲や細字の精度を保証しない。
- 会場条件: PCなし、開始後のスマホ操作0回、スマホAPと携帯回線を併用しChromeを前景・点灯に保つ。
  通常20～40ページ、リスニング30分の原音、約150分の利用が対象。時間は目標で、自動終了条件ではない。
- 出力条件: 正しい小問・解答欄に対応し、必要な単位・導出・図表を省かない。完成した小問から読めること。
- 保全条件: 保存・送信・解析・表示を区別し、中断、通信断、取り直し、終了後に原本や入力版を取り違えない。
- **実機操作・追加撮影・APK導入・GPT送信の停止は継続。** この整理や以前の試験手順は停止解除ではない。

本書は目的から機能の要否を判断する入口。[実装配置図](implementation-surfaces.md)は所在と役割、
[plan](../tasks/plan.md)は設計、[todo](../tasks/todo.md)は既存CQ/RPの実施・合格条件を所有する。
[継続記録](../.agents/progress/pr37-capture-quality.md)はコマンド出力・原本照合・停止経緯を保持する。
旧番号の追跡表は下に残す。新しい並行タスクリストは作らない。

## 実機確認へ進むまでの順序

Runs on: 1～3はWindows PC。4は計画作成までPC、実行は停止解除の対象を特定してから。

1. **判読・登録**（CQ-5～8、RP-10）: 保存原本の必要領域を人手参照と比べ、縮小による損失と原本の欠けを分ける。
   候補保全と正式登録の境界を全入口で揃える。空OCRを不要ページ扱いしない。未校正値を合格閾値にしない。
2. **資料・小問・答案**（RP-11/12/14/15/16）: OCRで確定した不正な小問へ回答させず、原本の小問・解答欄を照合する。
   正しい入力版と保存済み答案を表示へ届け、未完了・失敗・資料不足を区別する。
3. **中断・終了**（RP-03/06/07/09/17/21）: 既存の保存・再送・入力競合の回帰を保ち、未接続経路をPCで検査する。
   原本を失わないこと、CLOSED後に無断再録音・旧答案混入がないことを先に確認する。
4. **限定測定→通し試験**（CQ-9、RP-01/13/18/20/22）: PCでは確かめられない撮影／表示／原音利用等を個別に測り、
   その後にAPの一周・反復・長時間へ進む。撮影だけの校正は通常読取やGPT送信と分ける。
   英語リスニングの実試験は、用紙から答案までの確認より後に置く。

測定を具体化する際は、答える疑問、同一の対象資料・照明、通常姿勢、標準カメラと対象APK、
原寸の同じ文字／図の比較箇所、原本hash・撮影対応、合格／保留／中止条件、送信の有無を先に決める。
**既存8枚の距離・姿勢・撮影組は未確認。最新2枚を着席基準にしない。**
倍率・cropは細字と必要範囲を両方比べる。拡大で失われた文字を復元できるとは扱わない。
測距や後退を利用者に強制せず、必要な枚数と各撮影の用途を説明できる条件だけを依頼する。

## 新旧機能の採否

| 判断 | 対象 | 理由／再検討条件 |
|---|---|---|
| 採用・接続 | 起動二択＋前回選択、即取得、背景転送、段階的答案、任意の前回答案 | 毎回の操作と待ち時間に直接効く。新しい画面階層を増やさない |
| 採用・補強 | 3秒確認、単タップ手動／取り直し、独立した終了、入力版、原音保全 | 一度しか取れない音声と誤ったページ対応を守る。速度のために省略しない |
| 統合 | 全文OCR＋大問画像＋必要な音声根拠、同一教科の1チャット | 文書全体の文脈と細部を併用。既存大問選択と添付再利用を活用 |
| 比較用に限定 | PDF／2～3ページ結合 | 利用者の設定メニューにしない。同一資料・同一モデルの誤読と正答で既定方式を決める |
